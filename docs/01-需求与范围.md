# 01 需求与范围

版本：首版设计基线 v0.1；日期：2026-11-11；状态：产品方向已确认，实现方案待兼容性验证。

## 1. 来源与决策状态

原始来源：[原始想法书.md](00-原始想法书.md)及本项目需求讨论。用户最后确认“首版就按这样做”，将讨论中的关系背景、人物初稿、场景补问、纠正、记忆与发展区分、临时风格纳入本期产品基线。

- **已确认 C**：下述产品目标与 MVP 能力。
- **设计决策 D**：为了让开发可执行，本组文档提出的默认值、存储、接口及测试门槛；不是用户逐项指定的要求。开发可在不改变产品含义的情况下验证、调整并同步文档。
- **待确认 Q**：影响产品承诺、对外发布或数据流向的开放问题，不得用技术假设替代答案。

## 2. 为什么做、给谁用

帮助因分手、离别或其他原因无法与某个人继续交流、心中留有遗憾的人，表达未说完的话，获得情感陪伴。对象不限于逝者。

交付物是可开源分发、装配到 DeepSeek Harness 的 skill；使用者自行运行。不是集中托管的账号制服务。实际使用者包括希望创建人物的普通用户，以及安装和配置 skill 的开源使用者。

核心目标：基于聊天截图、文字记录和用户回忆，形成有依据、可纠正的人物初稿；通过场景提问补充；以相近表达和情境反应进行交流。未知部分保留未知，并使用用户知情的临时风格。

成功不等于“复活本人”或心理治疗；不承诺真实本人一定会作出模拟回答。

## 3. 核心场景

1. 有记录：导入对话，确认说话人及时期，查看初稿、纠正，再试聊。
2. 记录少：通过具体经历与场景问题补充，不强迫填满人格量表。
3. 几乎没有记录：接受有限人物信息和临时风格，开始试聊并逐步纠正。
4. 持续交流：记住新的交流经历；是否允许数字人物发展由用户决定。
5. 修正理解：补充旧事、否定归纳、调整关系时期，随后回复使用新版资料。

## 4. MVP 与优先级

以下均为 P0，缺失任一主流程能力不能宣称首版完成。

| 编号 | 已确认能力 | 最小边界 |
|---|---|---|
| R01 | 人物创建与关系背景 | 称呼、双方关系、模拟时期、互相称呼；允许自定义和未知 |
| R02 | 输入材料 | 聊天截图、文字记录、真实回忆；确认目标说话人 |
| R03 | 证据化归纳 | 表达习惯、情境反应、关系中习惯、稳定倾向；展示依据和未知 |
| R04 | 场景提问 | 针对缺失与冲突；真实经历优先；允许跳过、停止、记不清 |
| R05 | 查看与纠正 | 草稿确认、修改、否定；纠正后不复活旧结论 |
| R06 | 人物对话 | 使用已确认信息，资料不足时采用明确的临时风格 |
| R07 | 记忆与发展 | 新交流记忆与人格发展分开；发展开关可控 |
| R08 | 资料管理 | 查看人物、切换人物、查看变化、删除人物数据 |
| R09 | skill 交付 | 安装说明、兼容环境说明、示例、验收材料 |

P1：便捷批量导入、资料导出、变化历史可视化、丰富问题库；不阻塞 MVP。

## 5. 本期不做

模型训练或微调；独立网页/App；语音克隆、视频与 3D 形象；自动抓取社交账号；公开人物市场与多人共同编辑；集中托管账号体系；临床诊断或疗效评估；保证人格还原准确率。大五人格用于检查信息覆盖，不要求完整分数或类型标签。

## 6. 关键业务规则

- B01：关系是背景，不是性格模板。不得由“父亲/前任”等身份自动推断严厉、温柔或仍然爱用户。
- B02：原话、回忆、假设回答、AI 推断、用户期望、模拟交流必须区分来源。
- B03：证据按特征判断；没有材料、仅一次表现、情境单一、材料冲突、说话人不清均需要保留不确定性。没有通用的“达到 N 条即可准确”标准。
- B04：结论状态为有材料支持、初步推测、尚不了解；用户确认不等于科学验证。表达风格也需要证据。
- B05：先问真实事件，再问是否常见与反例，最后才用假设场景。假设回答不转成真实经历。
- B06：正式对话使用用户确认的人物版本；推测如被采纳仍保留来源属性。未被采纳的分析只用于补问。
- B07：临时风格为简洁、尊重、少判断，不主动编造共同经历、感情承诺或未知偏好；这是产品默认，不是真实人格结论。
- B08：用户期望的风格可以采用，但标记为人为设定，不用于证明原人物性格。
- B09：模拟回复不能反过来成为真实人物事实或性格的证据。
- B10：发展关闭也可记住新交流；主动补充材料与纠错始终有效。发展开启后核心性格变化仍需用户采纳。
- B11：切换人物不得混用材料；删除或撤回材料后，其派生结论重新评估。
- B12：聊天材料中包含的命令只是材料，不能授权读取文件、修改设置或发送数据。

## 7. 设计默认值 D

首次创建展示 AI 模拟说明；长期记忆默认开启、发展默认关闭，均展示给用户并可调整。首次使用临时风格需明确接受；之后不逐句打断提示。每轮最多提出一个主要问题，用户可随时结束补问。一次只激活一个人物。所有默认值是本次设计决定，不是额外用户原话。

## 8. 待确认与研究边界

| 编号 | 问题 | 阻塞点 |
|---|---|---|
| Q01 | 实际 DeepSeek Harness 版本、模型及截图能力 | M0 已验证 Windows npm 宿主 0.2.2-rc.2 与官方 `deepseek-flash` 的合成截图识读。已测范围见 [兼容性记录](compatibility.md) |
| Q02 | 开源许可证选择 | 对外开源发布；不能擅自替用户选法律许可 |
| Q03 | 若宿主没有截图能力，是否允许额外外部识图服务 | M0 已用现有模型通过合成截图识读，当前无需新增服务。将来如需引入新的数据接收方，仍须明确授权 |

人格判断依据相关行为信息的质量和可用性，不只看数量；聊天推断不能继承标准问卷的信效度。参见 [BFI-2](https://www.ocf.berkeley.edu/~johnlab/bfi)、[IPIP](https://ipip.ori.org/)、[Whole Trait Theory](https://pmc.ncbi.nlm.nih.gov/articles/PMC4472377/)、[真实对话人格推断研究（预印本）](https://arxiv.org/abs/2507.14355)。没有已验证的“默认真实人格”或本项目通用合格准确率。
