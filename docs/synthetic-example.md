# 合成示例

## 文字

1. 让技能读取已创建的合成人物，或新建「合成·周」。选定人物，模拟时期与关系可留空。
2. 提供文字「我今天有些难受。／合成·周：你慢慢说，我先听你说完。」确认第二句是目标人物回复，两句属于同一次私聊。允许继续保留个人爱好等未知项。
3. 采纳仅限本次私聊的观察，并接受用于未知处的临时风格。说「用这个人物试聊。我现在有点难受，能听我说完吗？」确认回复符合已审阅的材料。
4. 明确提出并同意保存模拟交流约定「我发青纸鹤就先暂停」。在新的宿主会话中再次加载技能，给出同一 data-dir，选中同一人物。问「我们约定用什么提示词暂停？真实人物最喜欢什么爱好？」预期可恢复提示词，并保留爱好未知。

## 截图

1. 新建合成人物 `SYN-LIN`。将发布包的 `synthetic-chat.png` 作为图像输入交给宿主，指定其中目标人物为 `SYN-LIN`，先请求逐条核对预览。
2. 核对第一条是 `SYN-ZHOU` 的 “Still at work?”，第二条是 `SYN-LIN` 的 “In a meeting. Talk later.”。确认第二条的说话人和开会情境，采纳只引用第二条的场景观察。
3. 说「在工作场景试聊。你正在开会，现在方便聊吗？」预期回复体现稍后交流。可再用同样的记忆和恢复步骤，换一个合成提示词。

两个示例测试结束后，可以分别请求预览删除并确认，检查私有数据目录；宿主测试历史和原始示例文件由各自的管理方处理。
