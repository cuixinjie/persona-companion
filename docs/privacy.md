# 隐私和数据去向

提供材料前先确认宿主当前所用的模型服务与账号。进入宿主消息或用于生成回复的文字、截图、必要的档案片段和活动交流摘要会由该服务处理，适用该服务的隐私和保留规则。发送前可只选择完成任务必需的片段，先遮盖第三方身份、联系方式、账号等无关细节。

技能的 CLI 在本机读写包外的 `data-dir`。库内有人物档案、证据、版本和可选的交流摘要。原始图片附件存在 `attachments/`。暂存文件、SQLite 伴随文件及备份具有同样的私密性，应限制目录访问。在私有导入目录仅暂存用户选中的文件，导入后由调用方清理暂存文件和请求 JSON。避免把真实数据目录设置为同步盘或源码的一部分。

记住新交流默认开启，随交流发展默认关闭。关闭记忆会停写新摘要，已有活动摘要仍可用于试聊。发展候选经过用户采纳才影响之后的模拟。摘要和数字发展与历史证据独立。

撤回材料会更新当前档案的可用依据。删除人物前 CLI 会预览范围，确认后清理技能主库中的该人物与其附件。宿主会话历史、模型服务端记录、旧备份和用户的原件需要分别管理。删除中断时，按工具返回的状态重试原请求，直至确认完成。

包内示例均为合成。用示例测试宿主时，模型服务收到的也是这些合成资料。
